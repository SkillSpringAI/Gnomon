# Gnomon Documentation Archive

This directory contains documentation retained for historical context. Archived documents may describe earlier designs, baselines, plans, implementation states, or authority drafts and may be inconsistent with the current implementation.

Archived documents are non-normative. They are not the correct starting point for understanding current Gnomon behavior, and active documentation must not depend on them for current requirements. Start with the [documentation map](../README.md), [current source of truth](../development/source-of-truth.md), [architecture](../architecture/overview.md), and [conformance](../development/conformance.md).

## Archive areas

- `original-authority-documents/` — original DOCX authority artifacts retained after verified Markdown conversion.
- `superseded-plans/` — dated plans, roadmaps, gap registers, and source-of-truth snapshots superseded by maintained development documents.
- `completed-slices/` — dated reviews and completed-slice evidence retained for historical reconstruction.
- `legacy-designs/` — earlier architecture, project, and investigation documents retained for context.

The 26 September C1 snapshots in `completed-slices/` and `superseded-plans/` preserve the former source-of-truth journal, implementation-status chronology, and detailed M0/M1 roadmap before their lifecycle reduction. Their original checkpoint claims may conflict with later hosted evidence; follow the maintained documents for current scope.

If an archived document is cited, treat it as historical evidence and verify any claim against the current maintained documentation, implementation, and tests.
